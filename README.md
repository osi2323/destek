# Destek Kartları Başvuru Sistemi — Demo

Bu proje yalnızca sunum/prototip amaçlıdır. Herhangi bir kamu kurumunu temsil etmez ve gerçek kişisel veri toplamamalıdır.

## Lokal çalıştırma

```bash
npm install
npm run dev
```

Ardından terminalde verilen localhost adresini açın.

## Vercel

Projeyi GitHub'a gönderip Vercel'de import edebilirsiniz.
Build Command: `npm run build`
Output Directory: `dist`

## Not
Supabase henüz bu demo sürümüne bağlanmamıştır. Sunum onayından sonra, yalnızca gerekli veri minimizasyonu ve uygun gizlilik metinleriyle güvenli şekilde eklenmelidir.
